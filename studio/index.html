Design rules

These are the published Caption with Intention rules, built into this studio and into an After Effects project you can save yourself. You do not need to request their project file. This is an independent implementation, not their template.

Attribution

Each speaker has a color. Six main colors are fixed: Yellow #E5E517, Blue #17E5E5, Red #E51717, Orange #E57E17, Green #17E517, Purple #E517E5. Space mains as far apart as the cast allows. A hero and a villain sit opposite each other. Supporting roles take the twelve hues between those mains. Minor and off-screen voices take pastels closer to white, and off-screen speech is italic.

Synchronization

The full line appears first in white at 90% opacity, so viewers can read ahead. As each word is spoken it shifts to the speaker color — through the word, not only at the end. The word also grows 15% and lifts, then returns. That pop is the timing mark. A word can be split into syllables when the performance breaks it that way (north|bound).

Intonation

Volume changes size, inside a fixed range: whisper 70% of baseline, conversation 100%, shout 142%. Pitch changes the Roboto Flex face: a low voice is heavier and wider, a high voice is lighter and more condensed. Sound effects are italic in brackets. Music descriptions are italic with a note mark. Sung lines keep the singer’s color and a note mark.

After Effects

Export → After Effects project, then in After Effects choose File → Scripts → Run Script File. The script installs the included Roboto Flex, builds a transparent caption comp and a black preview comp, and saves an .aep. Allow scripts to write files under Preferences → Scripting & Expressions. After Effects 26 sets the variable-font axes directly; older versions use size, horizontal scale, and faux italic. If the font was just installed, quit After Effects and run the script once more.

Picture setup

Baseline type size scales with the frame, the way the system sizes type per aspect ratio. Shouts grow from that baseline; they do not replace it.
